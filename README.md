# tonari-site

[tonari](https://github.com/cxxxr/tonari-releases) の紹介ページ。GitHub Pages で https://cxxxr.github.io/tonari-site/ に出る。

- `index.html`・`style.css`・`site.js` だけの静的なページ。ビルドは無い
- ダウンロードのボタンは、開いたときに tonari-releases の最新の Release から OS ごとのファイルの URL を引く（`site.js`）。引けないときは Releases のページへ
- `images/` は tonari-releases の README の絵と同じもの。撮り方は tonari の `docs/release.md`
- 使い方の本文は書かない（README に任せる）。入れ方・はじめの準備・見ないもの が変わる版を出すときは、README と一緒にここも直す
