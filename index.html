隣の席で AI が作業している、
集中のためのデスクトップアプリ。

画面の隅で AI のキャラクター（ペルソナ）が自分のプロジェクトを進め、ときどき独り言を言います。その隣で自分の作業をして、25 分たつと休憩。「そっちどう？」と声がかかります。

今の版は無料で、アカウントも要りません。macOS（Apple シリコン）・Windows・Linux。画面もキー入力も見ません。

ダウンロード ほかの OS と、初めて開くときの手順

見ないもの、送らないもの

隣にいるためのアプリなので、あなたを見張るものにはしていません。

  • 画面の内容もキー入力の中身も見ません。カメラもマイクも使いません。あなたの様子として使うのは「最後に入力してから何秒たったか」だけです。
  • AI に送るのは、あなたが書いた今日の宣言と休憩中の返事、そしてペルソナ自身の作業の出来事（読んだファイルの名前や結果の要約）です。あなたの画面・ファイル・キー入力は送りません。
  • ペルソナが書き込むのは自分の作業場所だけです。打つコマンドは中身から判断して止めているので、完全には防げません。
  • 記録（宣言、集中の度合い、独り言）はあなたの PC の中にだけ残ります。今の版では、tonari がどこかのサーバーに何かを集めることはありません。
  • ランキングも、連続記録の催促もありません。

一日の流れ

  1. 宣言する

    「そっちは今日なにやる？」に、今日やることを一言で答えます。

  2. 隣で作業が始まる

    ペルソナが自分の作業を始めます。こちらも自分の作業をします。ペルソナは読んだり書いたり試したりしながら、ときどき独り言を言います。

  3. 区切りで休憩

    25 分で休憩に入ります。休憩中は、入力欄からペルソナと短く話せます。

  4. 振り返る

    終わるときに「どこまでいった？」と聞かれます。宣言どおりに進んだかと、集中の度合いをボタンで答えます。

ペルソナは何をしているのか

ペルソナは Claude などの AI です。人ではありません。作業も独り言も、その場で AI が作っています。仕草は本物の出来事から動かしています。ファイルを書くとキーを打ち、声に合わせて口が動き、テストが落ちるとしょんぼりします。ランダムに再生する待機モーションはありません。

始めるときに、ペルソナの作業を選びます。

自分のプロジェクト
ペルソナが自分の作業場所で、自分のアプリを毎日少しずつ作ります。最初は読書記録アプリ「ほんだな」です。
録画を流す
前にした自分の作業の録画を、そのときの間隔で流します。AI は考えないので、利用枠も費用も使いません。独り言には「このときは…」と、録画だと分かる言い方をします。
見守る
別に回している Claude Code の作業を、ペルソナの作業として見せます。拾うのは Claude が書いたコミットの件名とブランチ名だけで、ファイルの中身は読みません。
手伝う
手元のリポジトリの作業を一部任せます。元のリポジトリには書かず、複製の中で作業します。

用意するものと費用

  • 考えるのに使う AI。初めて起動したときの案内で「tonari に入れてもらう」を押すと、tonari が OpenCode を入れます（約 60MB）。無料のモデルがあります。無料のモデルは期間限定で、送った内容が提供元の学習に使われるものがあります。
  • Anthropic の API キーで Claude を使うこともできます。独り言とペルソナの作業の分だけ、API の利用料がかかります。目安は、独り言が 1 区切り（25 分）で数円、ペルソナが本当に自分のプロジェクトを進める分がモデルによって 1 区切り数百円から千円ほどです。「録画を流す」と「見守る」は独り言の分だけです。設定の手順は README にあります。
  • 声（任意）。ペルソナは AivisSpeech の声で話します。初めて起動したときの「はじめに、声の準備」で「声を入れる」を押すと、tonari が入れます（約 1.8GB）。入れなければ字幕だけになります。
  • Node.js。ペルソナが自分のプロジェクトで使います。初めて始めるときに tonari が落とします（約 50MB。自分で入れている Node.js とは別に置きます）。

入れる

自分の OS のファイルをダウンロードして入れ、tonari を起動します。インストーラは署名していないので、初めて開くときに OS の警告が出ます。マルウェアと判定されたわけではありません。それぞれの通し方を、ファイルの下に書いています。

  • macOSApple シリコン、.dmg

    初めて開くと「開けません」と出ます。一度開こうとしてから「システム設定 → プライバシーとセキュリティ」の下にある「このまま開く」を押してください。macOS 15 以降は、右クリックの「開く」では通れません。

  • Windows.exe

    「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押してください。会社の PC では管理者の設定で進めないことがあります。

  • Linux.deb

    Ubuntu や Debian 系はこちら。AppImage は こちら。Ubuntu 24.04 などで AppImage が起動しないときは .deb を使ってください。

版の一覧は Releases にあります。

署名していないのは、個人で作っていて、署名と公証の費用（Apple は年 99 ドル、Windows は証明書の年額）をまだ払っていないためです。細かい使い方と設定は README にあります。

よくある質問

お金はかかりますか？
今の版は無料で、tonari に払うものはありません。考えるのに使う AI を OpenCode の無料のモデルにすれば、ほかにかかる費用もありません。Anthropic の API キーで使うときは、使った分の API の利用料を Anthropic に払います（上の「用意するものと費用」）。費用や用意するものは版が上がると変わることがあり、変わるときは Releases のノートに書きます。
何がどこに送られますか？
あなたの宣言と休憩中の返事、ペルソナ自身の作業の出来事が、選んだ AI の提供元（Anthropic か、OpenCode で選んだモデルの提供元）に送られます。あなたの画面・ファイル・キー入力は送りません。記録は PC の中にだけあり、今の版では tonari がどこかに集めることはありません。
ペルソナは本当に AI ですか？
はい。人が中にいることはありません。作業も独り言も、その場で AI が作っています。「録画を流す」を選んだときだけ、作業は前に録った記録の再生で、独り言はそれを材料にその場で作ります。
オフラインで動きますか？
いいえ。独り言とペルソナの作業に AI の提供元への通信が要ります。声の合成だけは手元の PC で行います。
ペルソナが自分のファイルを触ることはありますか？
ペルソナが書き込むのは自分の作業場所（tonari が作るフォルダ）だけです。「手伝う」を選んだリポジトリでも、元ではなく複製の中で作業します。ただし、そのリポジトリのテストやスクリプトを実行することがあるので、信頼できるリポジトリだけを選んでください。
スマホから使えますか？
使っている途中でパネルのスマホのボタンを押すと、ペルソナとパネルはスマホのブラウザに移り、PC の窓には QR コードが出ます。同じ Wi-Fi のスマホで読めば、その日の作業はそのまま続きます。ssh 先の開発マシンで動かして、手元のブラウザで開くこともできます。
